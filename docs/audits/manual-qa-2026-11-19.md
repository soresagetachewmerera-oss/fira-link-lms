# Manual QA script — 2026-11-19

Run on **staging** (never production), on a real Android phone, and on an iPhone if one is available.
Use a release-mode build pointed at staging: `flutter build apk --release --dart-define=BASE_URL=https://<staging-host>`.
Mark each row Pass / Fail and write what you saw. Rows marked **(known gap)** are expected to fail today — they confirm a
finding from `gap-analysis-2026-11-19.md`.

## Test accounts and data to create first

Staging helper: `QA_TOOLS_ENABLED=true` then `php artisan qa:seed` (see `docs/qa/QA_TEST_PLAN.md`). Make sure you have:

| Account | Setup |
|---|---|
| Guest | No account |
| New user | Phone sign-up, no intent chosen |
| Learner | Enrolled in one paid course with a **self-hosted** video lesson, one free lesson, one YouTube lesson |
| Buyer | Business role buyer, Tier 1 approved |
| Seller T0 | Exporter business, no documents |
| Seller pending | Documents uploaded, in review |
| Seller needs changes | One document sent back |
| Seller T1 / T2 | Approved; one published lot with evidence photos and a lab report |
| Seller suspended | Admin-suspended business |
| Seller expired | `verification_valid_until` in the past |
| Team member | Member of Seller T1, then removed during the test |
| Finance | Staff user with `finance` role and 2FA |
| Reviewer | Staff user with `reviewer` role and 2FA |
| Admin | Admin with 2FA |
| Blocked | Buyer that Seller T1 has blocked |

Data: one event with free and paid tickets, one tour with a future date and deposit, one open RFQ, one sample request,
one deal room at the deposit step with a confirmed payout account. Chapa: **staging test keys only**.

## Edge cases to try on every list and form

Airplane mode, then retry · very slow network (Android developer options → network throttling) · double-tap every submit
button · back button mid-upload · kill the app during an upload and reopen · 20 MB photo · PDF renamed to .jpg ·
1,000-character Amharic text · emoji and `<script>` in names · end of a long list (pagination) · a date in the past ·
phone clock set to another time zone.

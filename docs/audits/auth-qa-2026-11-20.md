# Manual QA: sign-in gating, guest protection, verification badges (2026-11-20)

Run on a **real phone** against **staging** (never production). Use a fresh install of the new build,
then repeat the guest section on a phone that still has an **older build signed in** (upgrade path).

Accounts (create with `php artisan qa:seed` on staging, `QA_TOOLS_ENABLED=true`):

| Who | What they are |
|---|---|
| G | Guest: no account, "Explore as guest" |
| U | Signed in, no business |
| B | Buyer business, Tier 1 approved |
| S1 | Seller business, verification **pending** (documents submitted, not reviewed) |
| S2 | Seller business, Tier 1 **approved** |
| A | Admin with an authenticator app |

Write down for every row: pass/fail, phone model, Android/iOS version, a screenshot when it fails.

## 1. Guest (G)

| # | Do this | Expected |
|---|---|---|
| 1.1 | Open the app, choose a language, tap **Explore as guest** | Home. No sign-in error, no "Guest User" with an avatar anywhere. |

| 1.4 | Marketplace → open a lot | Lot details show. Seller card shows a green tick **only** with "Verified · Tier N"; the licence line says "Export licence stated by the seller". |
| 1.5 | On the lot, tap **Save**, **Request sample**, **Request quote**, **Message seller** (one at a time) | The "Sign in to continue" sheet opens **before** anything loads. **Not now** closes it; nothing changes. |
| 1.6 | On 1.5 tap **Sign in or create account**, sign in with U's phone | After the code, you are back **on the same lot**. Tap the action again: it works (Save turns on, sample form opens). |
| 1.7 | Events → an event → **Book**; Tours → a tour → **Book**; Academy → a paid course → **Enroll** | Sign-in sheet or "Sign in to continue" screen first; no booking or payment page opens. |
| 1.8 | Coffee toolkit → **Calculator**: calculate | Result shows. **Save** asks for sign-in first. |
| 1.9 | Fira AI: ask 3 questions | Answers or "AI unavailable" (Gemini is off). After 30 questions in a day: "Too many" (429), no crash. |
| 1.10 | Verify a seller by Fira ID (S2's) | Business name, Tier 1. No phone, email, TIN or documents. |
| 1.11 | Old deep links: send yourself a push (staging admin → test push) with `type=deal_room, deal_room_id=<B's deal room>`; tap it as G | "Sign in to continue" screen, **not** the deal room. After sign-in **as U** (not a party): "not allowed" / "not available", never deal room 1. |
| 1.12 | Push `type=sample` without an id; `type=verification`; `type=rfq` | Sign-in screen first; after sign-in: samples list / verification / requests. Never sample 1. |

## 2. Upgrade path (phone that had an older build signed in)

| # | Do this | Expected |
|---|---|---|

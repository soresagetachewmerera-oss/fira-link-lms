# Fira Link screen flows (reference only)

One .dc.html file per screen. Open in a browser to see layout; read the HTML for exact text, spacing and tokens.
canvas.json lists every screen, its title, and its tag:
- NEW: the screen does not exist in the app yet. Build it from this design.
- MATCH TO YOUR APP: the screen already exists in the app. Existing app design wins. Use these only for flow, content and missing states.
Placeholders are in [brackets]. Never copy placeholder text into the app.
Tokens: Montserrat, #6D1A95 primary, #3B0764 deep, #F3E8FF tint, #F9F7FA scaffold, #1E1B4B text, #6B7280 muted. Radii: card 22, input/button 16, chip 12.
